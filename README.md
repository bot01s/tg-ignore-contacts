# tg-ignore-contacts

Локальная фича для Telegram Desktop: пользователя можно пометить как
«ignored», и его сообщения скрываются в групповых чатах.

## Возможности

- **Кнопка в профиле** любого пользователя — «Ignore» / «Stop ignoring»
  (рядом с «Block user»).
- **Хранение**: `~/.config/tdesktop/tg_cont_ignore.conf` (локально, на сервер
  ничего не отправляется). Список общий для всех аккаунтов.
- **Скрывается** только в группах и супергруппах. Каналы и личные чаты не
  затрагиваются.
- **Остаются видимыми**: сообщения с упоминанием меня (`@mention`) и ответы
  (reply) на мои сообщения; свои и служебные сообщения не скрываются.
- **Галочка «Show ignored messages»** в меню чата (три точки) временно
  показывает скрытые сообщения.
- **Пункт «Ignore list»** в главном меню — окно со списком всех игнорируемых
  (имя, аватар, `@username`); клик открывает профиль, «Stop ignoring» убирает
  строку.
- Переключение любого контрола сразу перестраивает уже загруженную ленту.

## Как поставить новую версию Telegram с фичей

Работает через агента/скилл по промпту: 

"**Установи Telegram Desktop и фичу ignore contacts**"

**ВСЁ!!!**

Ну и подождать часок пока скачает исходники, пропатчит их и скомпилирует

Скил очень декларативный но при этом детальный, так что должен справиться любой агент с самой дешевой нейронкой (codex + DeepSeek Flash справляется)

Для информации:

Вручную ключевые шаги такие:

1. **Подготовить чекаут** (репозиторий `telegramdesktop/tdesktop`, ветка `dev`):
   клонировать в подпапку `tdesktop/` текущей папки, инициализировать
   сабмодули, убедиться, что есть docker-образ `tdesktop:centos_env`.
2. **Применить фичу** — шаги 1–9 из `SKILL.md` (новые `core_ignore.*` и
   `ignore_list_box.*`, правки в `application`, профиле, истории, меню и
   строках локализации).
3. **Собрать Debug** (только Debug, не Release):

   ```bash
   docker run --rm -i -u $(id -u) -v "$PWD:/usr/src/tdesktop" -e CONFIG=Debug \
     tdesktop:centos_env /usr/src/tdesktop/Telegram/build/docker/centos_env/build.sh \
     -D TDESKTOP_API_ID=<id> -D TDESKTOP_API_HASH=<hash>
   ```

   Готовый бинарник: `out/Debug/Telegram`.

4. **Проверить в группе**: «Ignore» в профиле → сообщения исчезают; reply мне и
   `@mention` остаются; меню чата → «Show ignored messages»; гамбургер →
   «Ignore list».

## Креды

`api_id`/`api_hash` задаются при конфигурации. Хранятся в
`~/.tdesktop-api.txt` (две строки `api_id:` / `api_hash:`), вне репозитория.
Обёртка `~/.tdesktop-build.sh` читает файл и запускает сборку.

**Тестовые креды (`TDESKTOP_API_TEST=ON`, `17349` / `344583e...`) использовать
нельзя** — только реальные.

## Известные ограничения

- Счётчики непрочитанного и превью в списке чатов по-прежнему учитывают
  скрытые сообщения.
- Не применяется к каналам, веткам комментариев, темам, закрепу, поиску и
  просмотру медиа.
- Состояние «show ignored» сбрасывается при перезапуске.
- Файл списка не отслеживается — правь его только при закрытом приложении.
